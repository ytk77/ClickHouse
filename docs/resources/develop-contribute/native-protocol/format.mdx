# Native format specification {#native-format-specification}

The complete `Native` wire specification is maintained in this fork at
[`NativeFormat`](/interfaces/specs/NativeFormat). It includes the upstream `26.10`
encodings and the synchronous insert behavior of `UpsertMergeTree`.

For packet framing and version negotiation, see the
[native protocol specification](/resources/develop-contribute/native-protocol/protocol).
